# Puzzle Game

A small browser game collection with two simple puzzles:

- **15 Puzzle** — slide numbered tiles into order from 1 to 15.
- **Memory Tiles** — flip cards and match pairs as quickly as possible.

## Description

This project is built with plain HTML, CSS, and JavaScript. It includes a menu page where you can choose either the 15 Puzzle or Memory Tiles game. Each game tracks moves and elapsed time, and both include a reset option.

## Controls

### 15 Puzzle
- Click a numbered tile next to the empty space to move it.
- Use the arrow keys to move the empty space.
- Click **Shuffle** to randomize the board.
- Click **Reset** to return to the solved board.

### Memory Tiles
- Click a card to flip it.
- Match two cards with the same number to keep them flipped.
- Click **Reset** to shuffle and restart the game.
